Tailscale on the router

Put an Ericsson Cradlepoint router and the LAN behind it on your Tailscale network. Add one auth key in SDK Data, and the router downloads Tailscale, joins your tailnet, and advertises its LAN networks.

One key to get started

Create a reusable auth key in the Tailscale admin console, and add it as tskey in SDK Data. Nothing else is required.

LAN routes added for you

The app advertises each router LAN network to the tailnet, and you can add more routes, tags, and a hostname.

A proxy, not a full VPN

It runs Tailscale in userspace networking with a SOCKS5 proxy on port 1055, because an SDK app cannot run it as a routed VPN.

Overlapping subnets (4via6)

If several sites share a subnet, Tailscale's 4via6 feature can reach them. Pick a site ID from 0 to 65535 and, on a computer with Tailscale, run tailscale debug via [site-id] [subnet]. Add the resulting IPv6 subnet as a tsroutes value. Then reach devices by IPv6 or by a name like 172-16-0-1-via-1.

How it works

The app is a wrapper that downloads Tailscale and keeps it in sync with SDK Data.

Download once

It fetches the Tailscale release for the router's architecture from pkgs.tailscale.com and remembers the version it fetched.

Userspace and SOCKS5

It runs tailscaled with --tun=userspace-networking and a SOCKS5 proxy on port 1055. Incoming tailnet traffic to the LAN is possible too.

Routes

Every router LAN network is advertised automatically. Anything in tsroutes is added to that list.

Watches for changes

Every 10 seconds it re-reads tskey, tsroutes, tstags, tshostname, and tsserver. If one changes, it logs out and exits so the router relaunches it.

SDK Data settings

Only tskey is required. The others are optional ways to shape how the router joins the tailnet.

SettingRequiredDefaultWhat it does
tskeyYesNoneThe Tailscale auth key (tskey-auth...). Without it the app logs an error and exits.
tsroutesNoLAN networks onlyExtra routes to advertise, comma separated, such as 172.16.0.0/12. They are added to the router's LAN networks.
tsversionNo1.96.4Use this Tailscale version explicitly. Read when the binary is downloaded.
tshostnameNoThe router's system IDHostname to use in the tailnet. By default the system ID is used, with characters such as spaces and underscores replaced by hyphens.
tstagsNoNoneTags to request for this device.
tsserverNoTailscale's own login serverA self-hosted login server URL, such as a Headscale server.
  • Set fields in Ericsson NetCloud Manager under the device or group's SDK Data. The app checks every 10 seconds and restarts itself when tskey, tsroutes, tstags, tshostname, or tsserver changes.
  • Needs a Tailscale account, and the router needs internet access to download the Tailscale release the first time.
  • The app has no web page and no port to open. It runs Tailscale as a proxy, not as a routed VPN.
  • Security: depending on your tailnet configuration, any device on it may reach the router. Limit access with Tailscale access controls.
  • The key, hostname, and route values shown in this demo are samples.
