Mobile Site Survey

Drive the route and the Ericsson Cradlepoint router does the testing: with a GPS lock, Mobile Site Survey speed tests every connected modem each time you have moved at least 50 meters, and logs every result with its time, position, carrier, and signal.

Tests as you drive

With a GPS lock, a survey starts on its own each time the router is at least 50 meters from the last test point.

Every modem, same spot

Each survey measures every connected modem, so carriers are compared at the same place and time.

Nothing extra to install

The default netperf engine is built into NCOS: no server, binary, or license. Results are saved as CSV on the router.

    How it decides

    Tests when you have moved far enough

    On every pass of its loop, with a GPS lock, it measures the straight-line distance from the last test point. At min_distance (default 50 m) a survey starts. A survey has to finish before the next one can start, so at speed the points land farther apart than the setting.

    Every modem, pinned to its own WAN

    Each survey tests every connected modem, plus Ethernet and Wi-Fi as WAN with all_wans. netperf pins each test with its ifc_wan option, so no routing is added, and runs one modem at a time. iPerf3 runs them together, each on its own port from the range.

    What each result records

    UTC time, position, accuracy, carrier, download, upload, latency, jitter, packet loss, bytes, engine, server, and signal diagnostics, as one CSV per SIM in results/. Latency is measured on a quiet link. Packet loss comes from 10-ping runs to 8.8.8.8 on each modem between surveys.

    Other ways to start a survey

    Time-based tests run every min_time seconds (0 means back to back), and Run survey now runs one right away. Neither needs movement or a GPS lock. A surveyor router can also start tests on peer routers by calling them on port 8000.

    See it in the app

    SDK Data settings

    Nothing is required. Survey settings live in one JSON value named Mobile_Site_Survey, and the web UI's Save configuration writes it for you.

    SettingRequiredDefaultWhat it does
    Mobile_Site_Survey_web_port No First free port from 8000, then saved Web UI port (1 to 65535). Set it to pin the port; delete it and restart to pick one automatically again. Set it to 8000 on routers used as survey targets.
    Mobile_Site_Survey No Written from the code defaults on first start JSON object holding every survey setting. The keys a user usually sets are below.

    • Change settings in the web UI and press Save configuration; they apply right away. If you edit the JSON in Ericsson NetCloud Manager under the device or group's SDK Data instead, restart the app, because it reads the value at startup.
    • Open the web UI at http://router_ip:<port>. The port is in the app log at startup.
    • If LAN clients can't reach the page, add a zone firewall forward from the Primary LAN Zone to the Router Zone.
    • You need a cellular modem with a GPS antenna and a GPS lock for distance-based tests. An iperf3 server is needed only for the iPerf3 engine. No speedtest binary or license is required.
