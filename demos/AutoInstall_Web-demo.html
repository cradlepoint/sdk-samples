AutoInstall Web

On install day, nobody should have to guess which carrier is fastest at the site. AutoInstall Web has the Ericsson Cradlepoint router speed test every SIM and put the fastest download first in WAN priority, from one password-protected button. In that default mode, no Ericsson NetCloud Manager API keys are needed.

Fastest SIM goes first

Every SIM gets a speed test, then WAN priority is reordered by download speed. The fastest SIM gets the lowest priority number, so it becomes primary.

One button on site

The installer enters a password and presses Start AutoInstall. Or set autostart and it runs once on its own.

A record, or a groupoptional

Results go to SDK Data and an alert. In group mode the app moves the router to a matching NetCloud Manager group instead.

    How it decides

    One run, start to finish. The default mode reorders WAN priority; everything else is optional.

    Fastest download goes first

    SIMs are ranked by download speed. The fastest gets the lowest WAN priority number, set just below the lowest existing modem rule, with each slower SIM 0.1 behind. If SIMs share one WAN profile, the app splits it per SIM with a trigger_string for port and slot, and cleans up the rules it created. No NetCloud Manager API keys are needed.

    Every SIM tested the same way

    It tests the SIM that's already connected first, then switches to each other SIM and waits for it to connect. The test is the router's built-in netperf (10 seconds, both directions), or Ookla if an ookla binary is bundled. Each SIM gets up to 3 attempts. Fewer than 2 SIMs stops the run.

    Leaves a record

    On success it writes a one-line results summary to SDK Data, sends an alert (unless disable_alerts is set), and can copy the summary to custom1, custom2, or a config path such as asset ID. With autostart, an existing results field means it won't run again on reboot.

    Optional: group mode and a speed floor

    With group_by_carrier or group_by_sim, WAN config is left alone and the router moves to the NetCloud Manager group whose name has group_keyword (default prod) plus the carrier or slot, like prod_Verizon or prod_SIM1. That needs API keys. min_speed stops the run with an error if no SIM reaches it.

    See it in the app

    SDK Data settings

    Nothing is required. Out of the box it tests all SIMs and reorders WAN priority by download speed, with the router's serial number as the installer password.

    • Set fields in Ericsson NetCloud Manager under the device or group's SDK Data, or on the router under System > SDK Data. Restart the app after changing the web port.
    • Open the web UI at http://router_ip:<port>. The port is in the app log at startup.
    • If LAN clients time out, add a zone firewall forward from the Primary LAN Zone to the Router Zone. Actions need the installer password, so keep that forward to trusted networks.
    • Needs at least 2 SIMs and a working WAN. Dual-modem routers with up to 4 SIMs are supported.
    • NetCloud Manager API keys (Certificate Management) are needed only for group mode or custom1/custom2.
