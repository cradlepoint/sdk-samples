How it works

A web page in front of the bundled iPerf3 binary.

Client mode

Set host, port, protocol (TCP, UDP, or SCTP), direction, duration, parallel streams, and report interval. Source IP can bind the test to a LAN or WAN interface.

Server mode

Choose a listen port and bind address. The server runs until you stop it and accepts multiple clients.

History

Completed client tests are saved to tmp/iperf3_history.json, up to 500 entries.

One at a time

Only one test or server instance can run at a time. Client tests use iPerf3 JSON output internally.

SDK Data settings

Only the web port can be set. Everything else is chosen in the web page.

SettingRequiredDefaultWhat it does
iperf3_web_portNoFirst free port from 8000, then savedWeb UI port, 1024 to 65535. If set, the app uses exactly this port. If not set, it uses 8000, or the next free port up to 8100 if 8000 is busy, and saves it here only in that case. Delete it to pick automatically again. A bad value or a busy port stops the app and logs why.
  • Set it in Ericsson NetCloud Manager under the device or group SDK Data, then restart the app.
  • Open the web page at http://router_ip:<port>. The port is shown in the app log.
  • For LAN clients to reach the page, forward the Primary LAN Zone to the Router Zone in the router firewall.
  • Client mode needs an iPerf3 server the router can reach, on port 5201 by default. The bundled binary is for ARM64 routers.
  • Needs router firmware 7.26 or later.
