System monitor web

Watch your Ericsson Cradlepoint router's memory and CPU in a browser, with 24 hours of charts and an alert in Ericsson NetCloud Manager when either one passes your threshold. Defaults are 80% memory and 70% CPU.

Charts and history

A measurement every 60 seconds. The last 24 hours stay in memory and 30 days are kept on disk.

One alert per spike

An alert goes out when usage passes the threshold. It re-arms only after usage falls to 90% of the threshold or less.

A web page on the router

Open http://router_ip:<port>, or use Remote Connect from NetCloud Manager. The port is in the app log.

How it decides

A measurement every 60 seconds feeds the charts and the alert check.

Measures every minute

The first 2 measurements are discarded so the baseline is not skewed by the app starting up.

Alerts once

Usage above the threshold sends one alert through NetCloud Manager, and no more until it has been re-armed.

Re-arms below 90%

The alert re-arms when usage falls to 90% of the threshold or less. With 80%, that is 72%.

Keeps history

1,440 points (24 hours) in memory, 43,200 points (30 days) on disk, saved to disk every 10 measurements.

SDK Data settings

The only SDK Data field is the web port, and it is optional. Alert thresholds are set on the web page.

SettingRequiredDefaultWhat it does
system_monitor_web_web_portNoFirst free port from 8000, then savedWeb UI port (1024 to 65535). Set it to pin the port; delete it to pick one automatically again. Set it and restart the app to apply.
  • Set the port in Ericsson NetCloud Manager under the device or group SDK Data, then restart the app. The port in use is in the app log.
  • Open the page at http://router_ip:<port>. For LAN access, add a firewall zone forwarding rule from the Primary LAN Zone to the Router Zone.
  • Remote access: use a NetCloud Manager Remote Connect LAN Manager entry with HTTP, host 127.0.0.1, and the app's port.
  • Thresholds changed on the page apply at once and are held in memory, so they return to 80% and 70% after a restart.
  • The charts load their library from a public CDN, so the browser opening the page needs internet access.
