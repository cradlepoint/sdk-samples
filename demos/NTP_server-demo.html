GPS NTP server

Give a router accurate time from GPS, even with no internet. Cradlepoint routers have no battery-backed clock and boot thinking it is 1970. This app runs a stratum-1 NTP server from the GPS fix so the router and LAN clients can set their clocks.

Time without internet

The app serves NTP on UDP port 1123 from the router's GPS time. Point the router's NTP client at 127.0.0.1 port 1123.

Silent until GPS locks

The NTP port stays closed until the first GPS time arrives, so a client never takes an early "unsynchronized" reply.

A dashboard and a clock setter

Watch sync status in a web page, and set the router clock from GPS, your browser, or a picked time.

Status the app publishes

The app publishes its state to status/ntp_gps every second. state is waiting, synced, holdover, unsynced, or stopped. Other fields include synced, serving, ntp_requests, dispersion_ms, and the GPS and router times.

How it works

Time comes from GPS, and the app is careful about when it answers.

GPS source

It reads GPS time from status/gps/nmea, which behaves the same on every router model.

Port opens on lock

No fix means a closed NTP port and a waiting status. The port opens when the first GPS time arrives.

Holdover

After GPS stops, it keeps serving for the holdover window (300 s by default), then reports unsynchronized.

Accuracy

Roughly a few hundred milliseconds. Coarser than a PPS-disciplined server, but it needs no per-hardware setup.

SDK Data settings

Nothing is required. Defaults are applied in code, and the app writes nothing to SDK Data except a discovered web port.

NTP_server_web_portNoFirst free port from 8000, then savedWeb UI port (1024 to 65535). Set it to pin the port; delete it and restart to pick one automatically again. A busy configured port is retried for about 10 seconds, and the NTP server keeps running if the web page cannot start.
  • Set fields in Ericsson NetCloud Manager under the device or group's SDK Data. The two NTP settings are read once at startup, so restart the app after changing them.
  • Point the router's NTP client at 127.0.0.1 port 1123 (Administration, System, Time).
  • Open http://router_ip:<port> for the dashboard. The port is in the app log, usually 8000. LAN clients need firewall zone forwarding from the Primary LAN Zone to the Router Zone.
  • Needs GPS enabled on the router and an antenna with a clear view of the sky.
