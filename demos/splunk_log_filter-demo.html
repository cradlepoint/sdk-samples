Splunk log filter

Send only the router log lines you care about to Splunk, as they happen. An Ericsson Cradlepoint router tails its system log, keeps lines that match your filter text, and posts each one to the Splunk HTTP Event Collector.

Filter at the source

Lines that do not match your filters never leave the router, so Splunk gets the events you asked for.

Each event is labeled

Every event carries the router host name, serial number, MAC address, and firmware version.

Set up in SDK Data

A URL, a token, and one or more filter texts. No web page and no port to open.

How it works

The app follows the system log and checks each new line against your filters.

Follows the system log

It tails /var/log/messages and handles new lines only.

Matches your text

A line is sent if it contains any filter text, ignoring upper and lower case. Every SDK Data field whose name starts with splunk_filter counts.

Posts to Splunk

Each match goes to the HTTP Event Collector with your token, plus host name, serial number, MAC, and firmware version.

Waits for setup

If the URL or token is missing, it logs that and checks again after 60 seconds.

See it in the app

SDK Data settings

The URL and token are required. Filters are optional, but with none set every log line is sent.

SettingRequiredDefaultWhat it does
splunk_urlYesNoneThe Splunk HTTP Event Collector URL, for example https://your-splunk-instance.splunkcloud.com:8088/services/collector.
splunk_tokenYesNoneYour HTTP Event Collector token.
splunk_filterNoNone (all lines sent)Text to match in a log line, for example Client SSH session started.
  • Add more by naming fields splunk_filter2, splunk_filter3, and so on. Any field starting with splunk_filter is used.
splunk_filter2NoNoneA second filter text, for example Client session ended.
  • Set the fields in Ericsson NetCloud Manager under the device or group SDK Data. The app reads them when it starts and then follows the log, so restart the app after changing them.
  • The router needs network access to your Splunk collector.
  • The app does not verify the Splunk server's TLS certificate.
  • The app has no web page and no port to open.
