Logfile

Never lose a router log. The app saves the syslog to files on flash, keeps them across reboots, and lets you download them over HTTP, including remotely through Ericsson NetCloud Manager Remote Connect.

Logs survive reboots

Messages are written to timestamped files on flash storage, so you can recover them after a reboot.

Rotates by itself

A new file starts at 100 MB, and only the 10 newest files are kept.

Download with a browser

Browse to the router on port 8000 and click a file. No SSH and no USB drive.

How it works

A tail on the syslog, a rotation rule, and a small web server for the folder.

Tails the syslog

It follows /var/log/messages and writes each line to a file in the logs/ folder.

Readable timestamps

The numeric time at the start of each syslog line becomes a date and time such as 2022-11-11 09:52:25.

Rotation

Maximum size per file is 100 MB and the backup count is 10. To change them, edit the variables at the top of logfile.py.

Download over HTTP

A simple web server on port 8000 lists the logs folder. Use LAN Manager through NetCloud Manager, or local LAN access with zone forwarding.

Setup notes

This app has no SDK Data fields to set. Size and count limits are variables in the code.

  • Remote access: in Ericsson NetCloud Manager open the device, then use LAN Manager to connect to 127.0.0.1 port 8000 over HTTP.
  • Local access: add a firewall zone forwarding rule from the Primary LAN Zone to the Router Zone, then browse to http://router_ip:8000.
  • The port is fixed at 8000. It does not use the automatic port discovery.
  • Needs router firmware 7.26 or later.
