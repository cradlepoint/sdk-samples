Ericsson Cradlepoint · NCOS SDK sample

USB alerts

Get an Ericsson NetCloud Manager alert the moment a USB device is plugged into or removed from an Ericsson Cradlepoint router, so nobody can swap a device without you knowing.

Connect and disconnect

One alert when a USB device appears and another when it is removed, each with the device number.

Reads the system log

The app follows /var/log/messages and reacts to the kernel's USB messages as they are written.

Nothing to configure

No SDK Data fields and no web page. Install it and it starts watching.

How it decides

Two text matches on the system log, and one alert for each.

Follows the log

It tails /var/log/messages and handles each new line.

Connect

A line containing "speed USB" becomes USB Connected: ....

Disconnect

A line containing "USB disconnect" becomes USB Disconnected device number ....

Physical devices only

The readme says only physical USB events are detected, not virtual or internal USB devices.

Setup notes

This app reads no SDK Data fields and has no web page. Install it and it starts watching.

  • The router needs a USB port (most models have at least one) and Ericsson NetCloud Manager connectivity so alerts can be delivered.
  • The app starts automatically and is restarted if it fails.
  • Needs router firmware 7.26 or later.
