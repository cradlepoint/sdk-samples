Client session monitor

See who on your LAN visited which domains, for how long, and with how much data. An Ericsson Cradlepoint router tracks the firewall connection table and turns it into sessions you can read on a web dashboard or download as CSV.

Sessions per client and domain

Each session records the client hostname, MAC, network, and SSID, plus start and end time, duration, and TX and RX bytes.

Ends after quiet time

A session ends when there has been no traffic for the timeout. The default is 60 seconds.

Dashboard and CSV

Active sessions and the last 100 finished ones show on a web page that refreshes every 3 seconds. History downloads as CSV.

How it works

Every 5 seconds the app reads the firewall connection table and compares it with the domains you list.

Domains become IPs

Each monitored domain is resolved to all of its IP addresses, so CDN and load balancer addresses still match.

Sessions keyed by MAC

A session is one client MAC plus one domain. It survives a DHCP IP change.

Quiet time ends it

If the byte counters do not move for the session timeout, the session is closed and written to history.

CSV with a size cap

Finished sessions append to a CSV. When it passes the size limit (10 MB by default), the oldest rows are trimmed.

See it in the app

SDK Data settings

Nothing is required. Out of the box the app monitors example.com with a 60 second timeout. You can also change domains and timeout from the gear icon on the dashboard.

SettingRequiredDefaultWhat it does
monitored_domainsNoexample.comComma-separated list of domains or URLs to monitor. Read on every pass.
session_timeoutNo60 secondsSeconds of inactivity before a session ends. Read on every pass.
log_size_limitNo10485760 bytes (10 MB)Maximum size of the CSV log. When it is exceeded, the oldest rows are trimmed.
client_session_monitor_web_portNoFirst free port from 8000, then savedPins the web dashboard port. If not set, the app uses 8000, or the next free port up to 8100, and saves it here only in that case. Delete it to pick a port automatically again.
  • Set fields in Ericsson NetCloud Manager under the device or group's SDK Data. Domains and timeout apply without a restart; restart the app after changing the web port.
  • The dashboard is at http://router_ip:<port>. The port is in the app log, usually 8000.
  • For LAN clients to reach the dashboard, the firewall needs zone forwarding from the Primary LAN Zone to the Router Zone.
  • Needs router firmware 7.26 or later. Session history is kept in memory (last 100), so it resets when the app restarts. The CSV stays on the router.
