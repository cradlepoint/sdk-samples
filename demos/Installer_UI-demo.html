Installer_UI

Set up a site's WiFi from one page, with just the installer password

Installer_UI serves a simple page on the Ericsson Cradlepoint router where an installer sets the WiFi name and password on both radios in one save. Every change is gated by a single installer password, which defaults to the router's serial number, so nobody needs the router's admin login. Before leaving, the installer can also run a speedtest and check the cellular signal from the same page.

How it works

Both radios, one save

Save settings writes the SSID and WPA passphrase to config/wlan/radio/0/bss/0 and config/wlan/radio/1/bss/0. The current SSID on the page is read from radio 1. All three fields must be filled, or the app answers Please enter all fields!

One installer password

Every save and speedtest is checked against installer_password in SDK Data, read fresh on each request. If it is empty or missing, the router's serial number is the password. A mismatch returns Incorrect Password! and logs it, and nothing is changed.

Speedtest and signal, on the spot

With an ookla, speedtest, or speedtest-cli binary in the app folder, it runs Ookla (90-second timeout). Otherwise it uses the router's built-in Netperf, 10 seconds each way. Signal monitor reads RSSI, SINR, RSRP, and RSRQ when the primary WAN is a modem, otherwise N/A.

Reachable from the LAN

At startup it adds a zone forward from the Primary LAN Zone to the Router Zone with the Default Allow All policy, unless one exists. The page uses the first free port from 8000, saved to Installer_UI_web_port, or the port you pin there.

See it in the app

SDK Data settings

Nothing is required. Out of the box, the serial number is the installer password and the port is picked for you.

SettingRequiredDefaultWhat it does
installer_password No The device serial number Password the installer enters to save WiFi settings or run a speedtest. If the field is missing at startup, the app adds it with an empty value, which still means the serial number.
Installer_UI_web_port No First free port from 8000, then saved Web UI port, 1024 to 65535. Set it to pin the port; delete it and restart to pick one automatically again. An invalid or busy port makes the app stop itself and log why.
  • Set fields in Ericsson NetCloud Manager under the device or group's SDK Data, or on the router under System > SDK Data. A new installer password applies on the next save or speedtest; a port change needs an app restart.
  • Open the page at http://router_ip:<port> from the router's WiFi or a LAN port. The port is in the app log at startup, for example Web server started on port 8000.
  • The app adds the Primary LAN Zone to Router Zone firewall forward itself, so LAN clients can reach the page.
  • For Ookla results, bundle an ookla, speedtest, or speedtest-cli binary in the app folder. Without one, the built-in Netperf test runs.
  • Signal monitor needs a modem as the primary WAN; otherwise each value shows N/A.
