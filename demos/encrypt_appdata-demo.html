Ericsson Cradlepoint · NCOS SDK sample

Encrypt appdata

Keep secrets out of plain sight in SDK Data. Name a field with enc_, secret_, password_, or encrypt_, and an Ericsson Cradlepoint router replaces the value with an ECC-encrypted copy on its own.

Encrypts by field name

Any appdata field whose name starts with enc_, secret_, password_, or encrypt_ is encrypted. Other fields are left alone.

Uses a certificate you add

It needs a Secp256r1 certificate named ecc in the router's certificate manager.

Quick to catch new values

It reacts when appdata changes and also checks every 30 seconds. Values that are already encrypted are skipped.

How it works

A name check, an encrypted-already check, and one certificate.

One-time setup

Add a Secp256r1 certificate named ecc in the router's certificate manager. Without it the app cannot start its encryption.

Prefix match

Names starting with enc_, secret_, password_, or encrypt_ are candidates.

Skip what is done

A value that is already encrypted is not encrypted again.

Event plus timer

It listens for appdata put, post, and delete events, and also re-checks every 30 seconds.

See it in the app

Setup notes

There are no SDK Data fields to set for this app. It scans every appdata field by name.

  • Prerequisite: add a Secp256r1 certificate named ecc in the certificate manager on the device. If it is missing, the app logs an error and does not encrypt.
  • The app has no web page and no port to open.
  • To encrypt or decrypt by hand, export the certificate and private key as certificate.pem and private_key.pem next to eccencryptor.py, then run it with a JSON string, or pipe one in.
  • Needs router firmware 7.26 or later.
