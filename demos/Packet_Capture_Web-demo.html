Packet capture web

Capture traffic on an Ericsson Cradlepoint router from a web page, or set it up once and let it capture on every boot. It streams to one pcap file and sends an alert to Ericsson NetCloud Manager when the disk threshold stops it.

Stream or download

Stream mode writes one growing pcap until you stop it or the disk threshold is hit. Download mode captures for a timeout or packet count, then saves the file.

Capture on every boot

Save your settings and turn on Auto Start. The router starts capturing by itself after each reboot.

Alert when the disk fills

The capture stops at your disk threshold and sends one alert to NetCloud Manager, so a long capture cannot fill the router.

What happens at the threshold

The code supports two disk actions in the saved settings. stop ends the capture. delete_oldest deletes the oldest saved capture and carries on, and stops only if that does not free enough space. The default is stop.

How it works

A web page on top of the router's own capture service.

Two modes

Stream writes one growing file. Download captures for a timeout in seconds or a packet count and then saves the file.

Filters and interfaces

Pick WAN devices, WAN profiles, LAN networks, Wi-Fi, or VLANs, and add a tcpdump-style filter such as dst port 80.

Disk check

Before a capture it checks the disk and will not start if it is already over the threshold. While streaming it keeps checking.

One alert, then it resets

The alert is sent once when the threshold stops a capture, and is armed again once usage falls below the threshold.

Setup notes

This app has no SDK Data fields to set.

  • Set pcap_defaults in Ericsson NetCloud Manager under the device or group SDK Data. It is read when the app starts, so restart the app or reboot after a change.
  • Web UI at http://router_ip:<port>; the port is in the app log (usually 8000). LAN clients need firewall zone forwarding from the Primary LAN Zone to the Router Zone to reach it.
  • Needs firmware 7.24 or later per the readme (the package file lists 7.26). Captures persist on flash across reboots.
