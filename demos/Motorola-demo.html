Motorola SmartConnect beacons

Tell devices on the LAN how the Ericsson Cradlepoint router is doing. Every 5 seconds by default the app broadcasts a UDP beacon with WAN, VPN, and GPS status for Motorola SmartConnect, and it sends one right away when something changes.

One broadcast, many listeners

A UDP packet with a JSON body goes to the broadcast address of each LAN you enable, on port 21010 by default.

Changes go out at once

If the primary WAN device or a VPN tunnel state changes, the app sends a beacon without waiting for the interval.

Set it up in a web page

Interval, UDP port, and which LANs broadcast are saved from the app's web page. No SDK Data editing needed.

How it works

  
One loop that checks once a second and sends when it is time or when something changed.

  
 On a timer
It sends a beacon when the interval has passed since the last one. The default is 5 seconds.
 On a change
It watches the primary WAN device and each VPN tunnel's state. If either changes, it sends immediately.
 What is in it
TimeStamp, ModemInfo (model, NCOS version), WANConnStatus, VPNStatus, and GNSSStatus when a GPS fix exists. Cellular entries add signal fields when reported.
 Which LANs
Only LANs you enable get a beacon, sent to that LAN's broadcast address. WAN devices reporting a no-SIM error are left out.

  • Clients on the LAN need firewall zone forwarding from the Primary LAN Zone to the Router Zone to reach the web page.
