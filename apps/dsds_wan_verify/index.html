Connectivity Tests

Ping and HTTP checks, configured per SIM slot and off until you enable them. Both only run while that slot is the connected one — a DSDS modem can have only one slot online at a time, so there is no way to probe the standby slot. Signal is the only test that works on both slots; it lives on Signal Thresholds.

Signal Thresholds

One threshold per SIM slot: the level at which this slot is no longer worth using. Signal is the only test that works on a disconnected slot, because a DSDS modem keeps reporting live diagnostics for the standby one, so the same number decides when to leave a slot and whether the other one is any better before paying ~30 seconds of downtime for a switch.
