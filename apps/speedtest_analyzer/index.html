Factory Reset

Factory Reset erases all Speedtest Analyzer-owned local data: canonical configuration (when device-managed), test history and history recovery files, saved reports, iPerf3 reliability statistics, and result output values. It leaves the application installed and never touches unrelated router configuration or NCM Group SDK Data.
